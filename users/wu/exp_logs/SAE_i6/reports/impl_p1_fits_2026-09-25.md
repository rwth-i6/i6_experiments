- `config/sae_i6_p1_fits.py` (setup dir): the entry point, with `p1_fits(rhos=(0.7, 0.8, 0.9), seed=0, *, register=True)`
  and `py()`. For each rho it calls `reverse_model.ladder.corrupted_phi(rho, seed_inputs=get_seed_inputs().seed_inputs,
  units_hdfs=inputs.data["train_units_hdfs"], eta_npz=inputs.data["eta_npz"], alias="sae_i6/p1/fits")` unchanged.
  These are the same seed inputs, unit HDFs and eta table that `config.supervised_init.gold_phi` gives the P0 gold
  phi, so the label source is the only delta. The config sets `phi.rqmt["sbatch_args"] = ["-p", "gpu_24gb"]`
  (`FIT_PARTITION`). It registers four outputs per fit, under `sae_i6/p1/fits/<tag>/`:
  - `phi_ep8.pt` (epoch-8 checkpoint);
  - `corruption.json`;
  - `corrupted_phones.json`;
  - `learning_rates.dev_loss_nll_per_frame` (RETURNN `learning_rates`; the dev NLL per frame is its column).

  A seed other than 0 raises `NotImplementedError`, because `corrupted_phi` hard-codes `CORRUPTION_SEED` = 0
  and takes no seed argument. A later entry point should call `p1_fits(register=False)` if the fits config
  is loaded in the same manager.
- `analysis/p1_nesting.py` (pure Python: json and argparse). For each consecutive pair by rho (r70 in r80,
  r80 in r90) and each utterance, it checks the following:
  - the smaller rho's substituted positions (positions that differ from gold) are a subset of the larger rho's;
  - those positions carry the same symbols;
  - the lengths are equal and no tags are missing or extra.

  It also reads the following from each `corruption.json` `parts.all`: the realised rate, rate minus rho,
  the adjacent-repeat delta (corrupted minus gold) and `differing_equals_substituted`. That last value
  validates using differing positions as substituted positions: the job never substitutes a symbol by itself.
  Following the coordinator's addition, it sets the i6 r70 counts beside JUPITER's banked r70
  (`CorruptSeedGoldJob.mnzDC7XJX00r`, seed 0: 2849 utterances, 351,312 gold tokens, rate 0.699905, repeats
  1705 / 14293). Each count gets an equal flag, and the rate is compared at 6 decimals. A difference is
  flagged but never fails. The script prints one JSON result. Usage:
  `python analysis/p1_nesting.py --gold <seed_gold_phones.json> --fit r70 <phones> <corruption> --fit r80 ... --fit r90 ...`.
  The gold path is
  `work/i6_experiments/users/wu/experiments/unsupervised_asr/data/gold/SeedGoldPhonesJob.BUWKmEsK2zTk/output/seed_gold_phones.json`
  (FINISHED).
- `analysis/test_p1_nesting.py`: 8 tests on a synthetic fixture:

  under 24 GB.
