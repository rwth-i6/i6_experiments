## 2. Suspicious code (from reading only; for the tests to probe)

- **S1 — where 1/tau applies.** NOTE l.155 puts 1/tau on log p_phi(z|B(a)) with p_phi the
  segmentation marginal; the code tempers every (path, segmentation) term (lattice.py:15-18, 928) and
  restricts segmentations per path through the band. Equal only at tau = 1 with a non-binding band;
  at tau = 2 the code sums Σ_seg p(z,seg|y)^(1/2), not (Σ_seg p)^(1/2). NOTE §4.1's fixed-point table
  then holds with w(a) replaced by P(B(a))·(Σ_{seg∈band(a)} p(z,seg|B(a))^(1/tau))^tau. T1.1, T1.11.
- **S2 — band convention.** Every lattice state is held to |s − 3t| ≤ W (lattice.py:73-77, 487-489,
  900-904; repeat arcs keep s, so each repeat frame must stay in band): the segment end is compared
  with 3(t_emit+1) and with every frame up to the next emission. NOTE l.161-163 states only "segment
  end within 25 of the emitting recognizer frame". T1.3.
- **S3 — pruned G not normalised.** prune_lm_tables re-derives back-off weights from the UNPRUNED
  lower orders (lexlat_k2.py:721-722) while pruning lower-order arcs in the same pass; the docstring
  claims each state still sums to one (lexlat_k2.py:680-685). Contexts of order ≥ 3 need not sum to
  one. Affects the default arm k2_word_lm and off4 (official 4-gram theta 5.0; training/arms.py:53;
  lm/lexlat_k2_official.py:951-955). T1.23(b).
- **S4 — tropical epsilon removal on a log-semiring total.** compile_hlg maps every disambiguation
  token to epsilon (lexlat_k2.py:872, incl. #0 back-off loops and the escape exit) then calls
  k2.remove_epsilon (:874), which the same module calls tropical-only (lexlat_k2.py:428-430). Safe only
  if no two epsilon paths join the same state pair. T1.22, T1.19.
- **S5 — L_lex sign and escape multiplicity.** An escape span can exit and a new <unk> span open at
  once (lexlat_k2.py:555-558), so one non-SIL span has several escape readings; back-off routes and
  homophones add parses; graph scores are divided by tau (lexlat_k2_train.py:444). Σ_parses
  exp(score/tau) is not bounded by 1, so "L_lex ≤ 0" (lexlat_k2_train.py:18-19) is not enforced;
  lexlat_k2.py:101-104 quotes "one <unk> per contiguous non-SIL span". T1.19(d,e).
- **S6 — segment order passed to k2.** chunked_tot_scores passes supervision segments to
  intersect_dense_pruned in batch order (lexlat_k2.py:1029-1031); log_z_h sorts them by decreasing
  duration citing a k2 requirement (lexlat_k2_train.py:496-506). T1.21.
- **S7 — lexicon term vs NOTE.** What runs is a separate added loss L_lex = log Z_HLG − log Z_H with
  its own normaliser, reading only the recognizer emissions (train_step.py:139-161;
  lexlat_k2_train.py:12-24); NOTE §5's first sentence described the cut trie DP. T1.20 pins it.
- **S8 — rho is a literal** 9.6619373279 (training/config.py:312); compute_rho was cut
  (rate_term.py:3-8). T3.7.
- **S9 — agg targets** come from smoothed Witten-Bell tables (agg.py:155-168); only the bigram is
  projected onto the run-collapse support (blankfree_model.py:483-487; blankfree.py:21-25); the EMA
  runs over per-step normalised frequencies (agg.py:36-39). T1.17.
- **S10 — stale docstrings** (lattice.py:20-23 "T = S"; lattice.py:53-54, 78-80 SIL after SIL;
  emc_model.py:31-33 stride 1). T1.1, T1.4(c).
- **S11 — apply_spec_augment=True on the frozen tap** (w2v2/forward.py:112); masking stays off only
  because the module is in eval (forward.py:156-158). T3.2.
- Note for oracle writers: the prior is stored as a float32 buffer (emc_model.py:396-403) and
  up-cast by the float64 DP (train_step.py:87,96); oracles must use the float32-rounded table.
